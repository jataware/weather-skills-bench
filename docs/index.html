Measurement notes & study diagnostics
  • Success is graded against deterministic reference answers. Workflow checks skill calls and artifact dependencies separately.
  • A saved answer can pass even if a later submission request hits a provider error. Time covers model calls and execution; environment setup is excluded. Tokens and cost include all requests in each scored attempt. Missing billing is shown as unknown.
  • Conditions and data-access modes are specified per experiment; the refined heat study compares Python + skills with Python only and includes Skills only as a diagnostic. It measures these agent configurations, not the complete Codex or Claude Code products. Historical protocols remain separate.
  • Success is reported with 95% Wilson intervals. Each experiment has a fixed task set; uncertainty estimates do not establish generalization to African operational forecasts.
